# feature: 手指カール調整と自然な曲げ改善

## 背景 / 目的
- 現状の指の曲がり具合が浅く、不自然に見える。楽器操作時に十分な握りが再現できない。
- XR 手モデルの視覚・物理挙動を自然にし、ピアノ鍵盤への押下体験を向上させる。

## ゴール
- 指カールの最大角・カーブ・デッドゾーンを適切に再設定し、自然な握り・伸展を再現する。
- 左右手で一貫した設定を適用できるプリセットを用意する。
- 過剰なカールでメッシュ貫通やコライダー不整合が発生しない。

## スコープ
- `HandCurlTracker` と `HandVisualFromCurl` 周辺のパラメータ調整（ScriptableObject 含む）。
- SteamVR/LucidGloves からの入力値をカール値にマッピングする処理のチューニング。
- 視覚用カールカーブと物理用カール値の分離・調整。

## 非スコープ
- ハードウェア（グローブ）側ファームウェアの変更。
- 新規手モデルの導入やリギング変更。
