# VR 設定パネル（オーバーレイ）要件定義

## 1. 背景・目的
- F1 で開く COM 設定に限らず、将来的に複数の設定パネル（通信、描画、デバッグ等）を同じ UX で開閉できるようにする。
- ワールド空間に置いたパネルを開いている間はゲーム進行を一時停止し、マウス操作に切り替えて確実に入力できること。

## 2. 対象スコープ
- Unity シーン上の「設定パネル」全般。内容は問わない。
- OpenXR 切替や SteamVR 設定ファイル編集など、プロジェクト設定の破壊的変更は含めない。

## 3. 前提・用語
- 「パネル」= 設定 UI のルート GameObject（Canvas 配下）。
- 「ヒント」= 「Press F1 ...」など常時表示するトースト的テキスト。
- デフォルト入力キーは `F1`。必要に応じてインスペクタで変更可。

## 4. 機能要件
### 4.1 開閉トグル
- `KeyCode openKey`（既定 F1）を押したフレームでパネル表示を反転。
- パネルを閉じた状態を初期状態とする。

### 4.2 表示状態に伴う挙動
- 開いたら `Time.timeScale = 0` にして一時停止、閉じたら元の値に戻す。
- 開いたら `Cursor.lockState = None` / `Cursor.visible = true`、閉じたら元の状態に戻す。
- パネルがワールド空間 Canvas の場合、開いている間だけ `RenderMode.ScreenSpaceOverlay` に切り替え、閉じたら元に復帰。

### 4.3 ヒント表示
- パネル非表示時のみヒントを表示すること。

### 4.4 拡張イベント
- パネルが開いた瞬間、閉じた瞬間に UnityEvent を発火できること（任意）。

## 5. 非機能要件
- 90Hz 実行時でも Update 負荷が無視できる程度であること。
- 例外発生やポート未設定の場合でもゲームがフリーズしないこと。
