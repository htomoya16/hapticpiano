# ピアノ鍵盤のドレミ表記（可視ラベル）

## 背景
- 被験者・体験者のピアノ経験にはばらつきがある。
- XR 空間で鍵盤の位置や音名を素早く把握できるよう、鍵盤に **ドレミ表記** を提示する。

## 目的
- 目線移動や迷いを減らし、タスク中の認知負荷を下げる。
- ガイド（光る鍵盤）と併用しても視認性が保たれる。

## スコープ
- `hapticpiano.unity` の鍵盤に、ドレミ表記を表示できること。
- 表示の ON/OFF、色、位置、#（黒鍵）の扱いをインスペクタから調整できること。

## 非スコープ
- テクスチャ焼き込み、フォントデザインの最適化、譜面 UI の実装
