# ストーリー: 触覚（ランタイム）通常追従・ピアノ接触モード・底面停止

## 目的
キャリブレーションで得た `released` 値を基準に、指の `curl01` と鍵盤状態（接触/底面）からサーボ目標値を生成し、触覚フィードバックを返す。

## 前提
- `released` は `story/haptics-serial-calibration.md` のキャリブレーションで得られる（0–1000）。
- `curl01` は `Assets/Scripts/Hands/Core/HandCurlTracker.cs` が提供する 0–1 の値。
- サーボ最大値は `servoMax=1000`。

## 受け入れ条件
1. 指ごとに `released` と `servoMax(=1000)` を使って制御量 `t(0–1)` を正規化できる。
   - `t=0` は `released`（緩み）、`t=1` は `servoMax`（最大）を意味する。
2. `curl01` と `t` は反対向きに対応させる（例：`t = 1 - curl01`）。
3. 通常時は指の `curl01` に追従してサーボ目標値を更新できる。
   - `airGapUnits` により、指に追従して計算した目標から `released` 方向へ一定値だけ離せる（一定ギャップ）。
4. 鍵盤に接触した指は、その指のみ「ピアノ接触モード」へ移行できる。
   - `pianoGapUnits` により、通常より指側にサーボを寄せられる（0推奨）。
5. 鍵盤が底面に到達した指は、その指のみサーボ更新を停止し、一定値で保持できる（指ごとに独立）。
   - 底面判定は、鍵盤の角度（例：`PianoKeyController.PressAngleThreshold`）や「底面到達」イベントを用いる。
6. 鍵盤の底面から離れたら（押下が戻ったら）、その指の更新停止を解除できる。

## メモ
- 本ストーリーは「ランタイム制御」に限定し、シリアル送信仕様やキャリブレーション方式は `feature/haptics-serial-calibration.md` に従う。
