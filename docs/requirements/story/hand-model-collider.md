# story-hand-model-collider — 見た目手直付けコライダ

見た目の手ボーンに直接コライダを付け、物理手プレハブに依存せず鍵盤との当たり判定準備を整える。

---

## 受け入れ条件（完了判定）

1. **コライダ配置**
   - 各指（親指〜小指）に 1〜3 本のカプセル／コライダを TIP から根元方向へ配置し、見た目ボーンに直付けされている。
   - コライダのレイヤー設定が統一され、ピアノ鍵盤のレイヤーと衝突するよう設定されている。

2. **追従精度**
   - HandVisualFromCurl が適用するボーン回転にコライダが正しく追従し、見た目と衝突位置のズレが目立たない。

3. **Rigidbody設定**
   - 手のルート（または適切な親）に kinematic Rigidbody が付与され、コライダが安定して移動する。

4. **パフォーマンス**
   - 物理手プレハブ（HandPhysics/HandCollider）は使用せず、直付けコライダで 60fps 目標を維持できる。

5. **デバッグ確認**
   - シーン内でコライダの有効/無効やレイヤー確認ができ、少なくとも一度は鍵盤オブジェクトと当たり判定が取れることを確認する。
