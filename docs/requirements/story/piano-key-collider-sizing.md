# story: 鍵盤コライダーを実寸に合わせる

## 背景
- 現状の鍵盤 `BoxCollider` がメッシュより小さく、XR ハンドの指先が視覚的に接触していても押下が発火しにくい。

## 目的
- 鍵盤モデルの見た目と物理判定を一致させ、意図した押下操作をしやすくする。

## 受け入れ条件
1. `hapticpiano.unity` の全ての `PianoKey.*` に付与された `BoxCollider` が、鍵盤メッシュのおおむね全長・全幅・全高を覆うサイズに調整されていること。  
2. XR ハンド（手コライダー）で鍵盤表面に触れたとき、視覚接触位置で押下が再現できること（隙間や極端な食い込みがない）。  
3. コライダー調整後も既存の `Rigidbody` と `HingeJoint` 設定で鍵盤が極端に跳ねたり貫通したりしないこと。  
4. 調整内容（基準寸法・適用手順）が記録され、再調整が必要になった場合に追従できるようになっていること（README 追記またはコメント等）。  

## ノート
- 実測が難しい場合はメッシュの `Renderer.bounds` を基準に 1〜2mm のマージンを持たせる。
- 物理安定性を優先し、必要なら `Physic Material` の摩擦/バウンスは現状維持とする。
