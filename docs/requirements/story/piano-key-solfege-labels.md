# story: 鍵盤にドレミ表記を表示する

## 背景
- XR 環境では実物の白鍵/黒鍵の感覚が掴みにくく、音名の把握も遅れやすい。

## 目的
- 主要タスク（Accuracy）で用いる `C4〜G4` の範囲を含め、鍵盤にドレミ表記を提示する。

## 受け入れ条件
1. `hapticpiano.unity` のピアノ鍵盤に、ドレミ表記（例：ド/レ/ミ/ファ/ソ/ラ/シ）が表示されること。
2. `C#` 等の黒鍵も必要に応じて表示できること（例：`ド♯`）。
3. 表示の ON/OFF、色、位置、回転、スケールがインスペクタから調整できること。
4. ガイド点灯（鍵盤の色変更）と併用しても、ラベルが消えたり破綻しないこと（ラベルは別 Renderer として扱う）。
