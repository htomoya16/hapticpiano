# story-hand-curl-tuning-basic — curl 正規化とキャリブレーション基礎

この story は、LucidGloves のポテンショメータ値を Unity に直接取り込み、  
指ごとの curl 値（0〜1）に正規化したうえで、  
VR 上の手の見た目と実際の手の動きが大きく破綻しないことを確認するための **最小セット** を定義する。

---

## 受け入れ条件（完了判定）

### 1. シリアル入力のマッピング

- Unity 実行中、シリアルで受信した文字列（例: `A2301B2391C3431D3313E1234`）が  
  以下の対応でパースされていることが確認できる:

  - A → 親指 (thumb)
  - B → 人差し指 (index)
  - C → 中指 (middle)
  - D → 薬指 (ring)
  - E → 小指 (pinky)

- デバッグ UI やログなどで、各フレームの生値 `sensorRaw[0..4]` が確認できる。

### 2. curl 正規化の挙動

- キャリブレーション後、以下が成り立つこと:

  - ホームポジション（腕を水平に伸ばし、指を伸展）の状態で  
    各指の `curl01[i]` が 0 に近い値（例: 0.0〜0.1）になる。
  - 最大押し込み（強く握る / 鍵盤を深く押す）状態で  
    各指の `curl01[i]` が 1 に近い値（例: 0.9〜1.0）になる。
  - 指ごとの差（親指だけ可動域が狭いなど）に対して、  
    個別に `sensor_rest` / `sensor_press` を調整可能である。

- 異常なキャリブレーション（`sensor_press ≒ sensor_rest`）を行っても  
  `curl01` が NaN や極端な値にならず、安全にフォールバックする。

### 3. 見た目と実際の手の一致

- キャリブレーション後、以下の感覚的な整合性が取れていること:

  - ホームポジションで、VR 上の手の形と実際の手の形が大きく乖離していない。  
    （指が明らかに曲がりすぎている / 反っている などがない）
  - 指をゆっくり曲げ伸ばししたとき、`curl01` の変化と VR 上の指の動きが  
    概ね同期して見える（遅延やガクつきが目立たない）。

### 4. キャリブレーション UI / 操作フロー

- ワールド空間の UI から、少なくとも以下の操作ができる:

  1. 「ホームポジションキャリブ」ボタン:
     - ユーザが腕を伸ばし、指を伸展した状態で押す。
     - `HandCurlTracker` が各指の `sensor_rest` を更新する。
     - `HandVisualFromCurl` が **現在の Visual Hand の姿勢を curl=0 の基準 (`baseRot`) として保存** する。
  2. 「最大押し込みキャリブ」ボタン（名称は任意）:
     - ユーザが最大屈曲（押し込み）状態で押す。
     - `HandCurlTracker` が各指の `sensor_press` を更新する。

- キャリブボタンを押したことがユーザに分かるフィードバック（ログ / テキスト表示 / 一時的な色変化等）がある。

### 5. デバッグ確認手段

- 少なくとも以下のどれかで、開発者が状態を確認できる:

  - インスペクタ / デバッグ UI 上で  
    `sensorRaw[i]` / `curl01[i]` / フィルタ後の curl などの値を表示する。
  - 必要に応じてログ出力を ON/OFF できる。

- 「センサ値 → curl → 指の角度」の流れが追えるようになっていること。
