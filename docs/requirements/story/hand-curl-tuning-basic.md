# story-hand-curl-tuning-basic — curl 正規化と Visual キャリブレーション基礎

この story は、ESP 側でキャリブレーション済みの LucidGloves ポテンショメータ値を Unity に直接取り込み、  
指ごとの curl 値（0〜1）に正規化したうえで、  
VR 上の手の見た目と実際の手の動きが大きく破綻しないことを確認するための **最小セット** を定義する。

---

## 受け入れ条件（完了判定）

### 1. シリアル入力のマッピング / フラグ

- Unity 実行中、シリアルで受信した文字列（例: `A2301B2391C3431D3313E1234`）が  
  以下の対応でパースされていることが確認できる:

  - A → 親指 (thumb)
  - B → 人差し指 (index)
  - C → 中指 (middle)
  - D → 薬指 (ring)
  - E → 小指 (pinky)
  - （オプション）K → キャリブレーション中フラグ

- デバッグ UI やログなどで、各フレームの生値 `sensorRaw[0..4]` が確認できる。
- `K` を含む行を受信しているかどうかを Unity 側で判定できる（例: `HandSerialInput.isCalibrating`）。

### 2. curl 正規化の挙動

- ESP 側のキャリブレーションにより、以下が成り立つこと:

  - 指を伸ばした（ホームポジション）状態で  
    各指の `sensorRaw[i]` が 0 に近い値になる。
  - 完全に握った状態で  
    各指の `sensorRaw[i]` が 4095 に近い値になる。

- Unity 側で `curl01` を 0〜1 に正規化した結果として、以下が成り立つこと:

  - ホームポジションの状態で `curl01[i]` が 0 に近い値（例: 0.0〜0.1）になる。
  - 完全に握った状態で `curl01[i]` が 1 に近い値（例: 0.9〜1.0）になる。

### 3. 見た目と実際の手の一致

- キャリブレーション後、以下の感覚的な整合性が取れていること:

  - ホームポジションで、VR 上の手の形と実際の手の形が大きく乖離していない。  
    （指が明らかに曲がりすぎている / 反っている などがない）
  - 指をゆっくり曲げ伸ばししたとき、`curl01` の変化と VR 上の指の動きが  
    概ね同期して見える（遅延やガクつきが目立たない）。

### 4. キャリブレーション UI / 操作フロー

- ワールド空間の UI から、少なくとも以下の操作ができる:

  1. （ESP 側 or 外部 UI）キャリブレーション開始:
     - ESP 側から `K` フラグ付きのシリアル文字列を送信し始める（`...K` を含む行が連続する）。
     - Unity 側では `HandSerialInput` が `isCalibrating = true` となり、  
       `HandCurlTracker` へのセンサ更新を停止する（指の curl が凍結する）。
     - `HandFreezeOnCalibrate` などを通じて、VR 上の手の位置・向きが凍結される。

  2. 「ホームポジションキャリブ」ボタン:
     - ユーザが VR 上の手の位置に合わせるように実際の手を動かし、指を伸展した状態で押す。
     - ESP 側でのセンサキャリブレーションは完了している前提とし、  
       Unity 側では追加のセンサキャリブレーションは行わない。
     - `HandVisualFromCurl` が **現在の Visual Hand の姿勢を curl=0 の基準 (`baseRot`) として保存** する。

  3. キャリブレーション終了:
     - ESP 側が `K` フラグを送信しない状態に戻す。
     - Unity 側では `isCalibrating = false` となり、センサ更新と手の追従が再開する。

- キャリブ中・完了時にユーザに分かるフィードバック（ログ / テキスト表示 / 一時的な色変化等）がある。

### 5. デバッグ確認手段

- 少なくとも以下のどれかで、開発者が状態を確認できる:

  - インスペクタ / デバッグ UI 上で  
    `sensorRaw[i]` / `curl01[i]` / フィルタ後の curl などの値を表示する。
  - 必要に応じてログ出力を ON/OFF できる。

- 「センサ値 → curl → 指の角度」の流れが追えるようになっていること。
