# story: 手指カールを自然にする（基礎調整）

## 背景
- 現状の指が「曲がらなさすぎる」と感じられ、ピアノ演奏時の握り・押下が不自然。

## 目的
- 入力カール値のマッピングとビジュアル表現を調整し、自然な曲げ量と曲がり方を実現する。

## 受け入れ条件
1. カール最大角（親指45°→60°付近、その他70°→80°付近など）が見た目に自然で、握りきったポーズが再現できること。  
2. デッドゾーン・ゲイン・カーブの調整により、軽い入力では滑らかに、強い入力ではしっかり曲がる非線形応答になっていること。  
3. 調整後もメッシュ貫通やコライダー破綻が発生しないこと（ハンドコライダーが指メッシュを大きく突き抜けない）。  
4. 左右手で同一プリセットを適用可能であること（`HandModelPreset` を更新し、両手で同じ見た目になる）。  
5. 調整手順と最終パラメータ値（deadZone, gain, smoothing, visualGamma など）が記録されていること。  
6. キャリブレーションは手元 UI のボタンまたは手コライダー接触で実行でき、クールダウン付きで誤作動を防いでいること  
   - 使用コンポーネント: `HandCalibrateTrigger`（UI OnClick と OnTriggerEnter/OnHandHoverBegin に対応）  
   - 旧来の物理キューブ専用トリガーは置き換え/削除されていること  

## ノート
- 視覚用のカールカーブ（`visualGamma` 等）と物理用カール値は分けてチューニングする。  
- SteamVR skeleton の生値が低い場合は deadZone を小さくし、gain を 1.1〜1.4 程度に抑えて試す。  
- しきい値と最大角は指ごとに微調整し、親指だけ別カーブでもよい。
