# story-hand-model-basic — 手モデル基礎の受け入れ条件

この story は、手の開閉を自然に見せるための **最小セット** を定義する。

---

## 受け入れ条件（完了判定）

### 1. curl 値と見た目の対応
- 手を開いたとき → 指がほぼ伸びた自然な形  
- 手を握ったとき → 自然な握りこぶしに近い形  
- curl 0〜1 の変化が滑らかに反映される

### 2. 不自然な挙動の排除
- curl 増加時に逆方向へ曲がる挙動がない  
- ゆっくり開閉したときにガクつきが目立たない

### 3. 左右手の整合性（必要時）
- 同じ動作で左右の見た目に極端な差がない

### 4. 将来の当たり判定への準備
- 指の Transform（MCP/PIP/DIP/TIP）が一貫した構造  
- Collider 追加時に困らない整理された階層

### 5. デバッグ確認手段
- curl 値や角度を確認できる UI / Gizmo / ログのいずれか  
- **シーンに常設されていること**
