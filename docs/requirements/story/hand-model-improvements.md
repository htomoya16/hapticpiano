# story-hand-model-improvements — 手モデル改善

この story は hand-model 基礎を拡張し、ノイズ抑制・左右整合性・Collider 連携準備・ワールド空間 UI からの再キャリブレーションに対応する最小セットを定義する。

---

## 受け入れ条件（完了判定）

1. **平滑化**
   - curl 入力にスムージング係数を設定できる。
   - ゆっくり開閉してもガクつきが目立たない。

2. **左右整合性**
   - 共通パラメータ（デッドゾーン/ガンマ/最大角度など）をプリセットとして共有し、デフォルトで左右の見た目差が極端にならない。

3. **キャリブレーション**
   - ワールドに固定配置した UI Canvas 上のボタン（左手用・右手用の2つ）を押して基準ポーズを再取得できる。
   - 再取得が失敗した場合は同ボタンでリトライできる。

4. **Collider 予備**
   - HandVisualFromCurl が指先アンカー Transform を保持し、指先に Collider を追加する際にスクリプト改変を要しない構造になっている。

5. **安全動作**
   - Skeleton 未取得時は curl 値をリセットするなど、未接続状態で指の見た目が暴れない。
