# story-hand-curl-filtering-noise-reduction — curl ノイズ低減

この story は、LucidGloves のセンサ値から得られた `curl01` に対して  
**ローパスフィルタによるノイズ低減** を行い、  
ピアノ演奏時に指先のガクつきが目立たない状態を実現するための最小セットを定義する。

---

## 1. この story の目的

- `feature/hand-curl-tuning.md` の 4.4 で予定されている  
  curl 値のノイズ低減（Filtering）を実装する。
- **追加レイテンシを最小限に保ちつつ、視覚的なガクつきを抑える** ことを目的とする。
- フィルタのパラメータ（強さ）はインスペクタから調整可能にし、  
  指ごと・左右手それぞれでチューニングできるようにする。

---

## 2. 対象コンポーネント

- `Assets/Scripts/Hands/Core/HandCurlTracker.cs`
- （必要に応じて）`Assets/Scripts/HandUICanvas/CurlDebugUI.cs` などのデバッグ UI

---

## 3. 受け入れ条件（完了判定）

### 3.1 フィルタリングされた curl 値の導入

- `HandCurlTracker` 内に、少なくとも次の 3 系列が区別されている：

  - `sensorRaw[i]` : ESP から届いた生センサ値（0〜4095）  
  - `curlRaw[i]`   : フィルタ前の curl 値（0〜1）  
  - `curl01[i]`    : フィルタ後の curl 値（0〜1、視覚・FFB が参照するメイン経路）

- フィルタはフレーム毎に次のような式で更新されている（指数移動平均または同等）:

  ```csharp
  // cRaw: フィルタ前の curl (0〜1)
  // cFilt: フィルタ後の curl
  // alpha: 0〜1 の係数（1 に近いほど追従が速く、0 に近いほど滑らか）
  cFilt = Mathf.Lerp(cFilt, cRaw, alpha);
  ```

- `alpha` は固定値ではなく、インスペクタから調整できるパラメータ  
  （例: `filterAlpha`）として公開されている。

### 3.2 過度な遅延を生まないこと

- 指を開閉したとき、**肉眼で明らかに遅れて見えるレベルの遅延** が発生していないこと。
- 開発者が `filterAlpha`（または同等パラメータ）を 0.0〜1.0 の範囲で調整し、

  - 0.0 付近では「ほぼ生値（フィルタなし）」に近い挙動  
  - 0.5 付近では「ガクつきが明らかに減るが、速い開閉でわずかに遅れを感じる」程度  
  - 1.0 に近づけると「ほぼ追従で、ノイズ低減効果が減る」

  といったトレードオフを確認できる。

- 最終的に採用する初期値において、

  - ゆっくりと指を開閉したときにガクつきが明らかに減っていること。
  - 速いスタッカート的動きでも、演奏に支障が出るほどの遅延は感じないこと。

（厳密な ms 計測まではこの story の範囲外とする）

### 3.3 ステップ変化へのフォロー（大きなジャンプを許容）

- センサの瞬間的なジャンプや、指を大きく動かした場合に  
  **フィルタが追従しきれず引きずる** 問題を抑えるため、以下のいずれかが実装されている：

  - 差分が大きいとき（例: `|cRaw - cFilt| > threshold`）には一時的に `alpha` を 1.0 に近づける。  
  - または、そのフレームだけ `cFilt = cRaw` で追従させる「スナップ」ロジック。

- 上記により、「意図的な素早い動き」が過度に丸められないことを目視で確認できる。

### 3.4 HandVisualFromCurl / FFB への適用

- 視覚側の指モーション（`HandVisualFromCurl`）では、  
  **フィルタ後の curl 値 (`curl01`)** を参照していることが確認できる。
- Force Feedback 用の `curlFfb` に対しても、  
  フィルタ後の curl から計算する方針であることがコード上で明示されている。

### 3.5 デバッグ表示

- `CurlDebugUI` などのデバッグパネルで、  
  少なくともどれか 1 つの方法で「フィルタ前 / 後」を比較できる：

  - 例: `sensorRaw` / `curlRaw` / `curl01` をそれぞれ別列で数値表示する。
  - または、フィルタ ON/OFF や `filterAlpha` の変更による見た目の違いを  
    ランタイム中に確認できるトグル／スライダーがある。

- フィルタを実質 OFF（`filterAlpha = 1.0` または類似設定）にすると、  
  ほぼ元の実装と同じ挙動になることを確認済みである。

---

## 4. 非機能要件

- フィルタ計算（1 フレームあたり 5 指分の数回の `Lerp`）は  
  VR フレームレート（90Hz）で実行してもパフォーマンス上問題ないこと。
- NaN や範囲外の `cRaw` が入ってきた場合にも、  
  `cFilt` が暴走して `Transform` に異常な値を送らないように  
  `Mathf.Clamp01` や簡単なフェイルセーフが入っていること。
